# v3.0.9

> [!IMPORTANT]
> ## 致 **Windows 10 version 1803 及以下系统** 用户
>
> 从后续 `v3.1.0` 开始，ReadBoard 将切换到新的 **WebView2 UI**。由于 WebView2 UI 和相关运行时要求变化，**Windows 10 version 1803 及以下系统将不再保证可以继续安装、启动或获得主线后续更新**。
>
> Windows 10 version 1803 及以下系统仅通过 WinForms 维护线选择性获得修复或功能更新；该维护线保持 `v3.0.x`，初始版本为 `v3.0.9`。如需继续使用主线最新功能，请升级到 **Windows 10 version 1809 及以上 / Windows 11**。

## 概述

v3.0.9 是现有 WinForms UI 的最后一个稳定版本，也是后续旧系统维护线和更新双通道的共同发布基线。

本版本新增按 Windows 版本选择兼容更新通道、SHA-256 安装包校验和宿主更新包 v2 能力协商，同时包含弈客落子稳定性、清空棋盘协议及同步竞态修复。v3.0.9 发布后将用于初始化 `main` 和 `legacy-windows` 通道，并作为 `legacy/winforms` 长期维护分支的起点。

## 主要变更

- 更新检查改为读取中央通道清单，根据当前 Windows 版本选择唯一兼容通道：
  - Windows 10 version 1809（build 17763）及以上选择 `main`。
  - Windows 10 version 1803 及以下系统选择 `legacy-windows`。
- 新增 active、retired、无匹配通道、当前版本高于通道版本等独立更新状态。
- 清单无效、范围重叠或网络请求失败时安全结束检查，不再回退 GitHub 全局 Latest Release。
- 下载更新包后先校验通道清单指定的 SHA-256，再检查 ZIP 结构和必需文件；校验失败时删除临时文件且不通知宿主安装。
- 新增 `readboardUpdatePackageV2Supported` 宿主能力协商：
  - 旧宿主继续安装 `readboard-github-release-<tag>.zip`。
  - WebView2 命名资产仅在宿主声明 v2 能力后提供托管安装。
  - `readboardUpdateReady` 消息格式保持不变。
- Release workflow 现在校验 tag、程序集版本、版本化 changelog 和资产名称，并同时生成 ZIP 与 SHA-256 sidecar。
- v3.0.x 继续使用 `readboard-github-release-<tag>.zip`；v3.1.0 起使用 `readboard-webview2-<tag>.zip`。
- 修复弈客几何信息缺失或失效时的自动落子行为，并补充跳过诊断。
- 新增专用 `clearBoard` 宿主协议，避免继续复用旧 `clear` 同步语义。
- 修复清空棋盘与停止同步之间的竞态，防止旧同步任务在清盘后补发棋盘状态。
- 修正原棋盘选点提示中的快捷键说明，使其与实际 `Ctrl+X` 热键一致。

## 兼容性

- v3.0.9 仍使用现有 WinForms UI 和旧命名发布资产，可由现有 v1 宿主继续托管安装。
- 现有 `readboardUpdateSupported` 和 `readboardUpdateReady` 协议保持兼容。
- WebView2 命名资产不会交给仅支持 v1 的旧宿主安装。
- 更新检查仍只由用户手动触发，不新增启动自动检查或用户可选通道。
- SHA-256 用于锁定通道晋升时审核的安装包内容，不替代代码签名。
- 本版本不包含 WebView2 UI；WebView2 主线将在后续 v3.1.0 发布。
