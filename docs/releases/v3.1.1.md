# v3.1.1

## 概述

v3.1.1 是 WebView2 主线在 v3.1.0 之后的第一个补丁版本。出厂窗口仍是 `1100 × 680`，但可以把常驻窗拖到更小，文字保持原生清晰；同时补上启动时的 Windows 版本门槛和 WebView2 Runtime 版本门槛，避免旧系统或过旧 Runtime 进入半初始化状态。

## 主要变更

- 常驻窗可以拖得更小，文字不再整页缩放发糊：
  - 出厂 / 无记忆尺寸仍是 `1100 × 680`，已记住的窗口尺寸不动。
  - 可拖最小客户区改为 `700 × 433`。
  - 小于基准尺寸时改用原生密度排版，不再使用整页 `transform: scale`。
- 缩小窗口时侧栏和高度连续跟手，不再在 `1100 × 680` 一刀切换档：
  - 变窄时先保住约 `870` 主区，侧栏从 `230` 收到 `48`。
  - 文字在宽度约 `1010` 隐藏，拉回到约 `1034` 才恢复。
  - 高度从 `680` 收到 `433` 时，标题栏、底栏和侧栏按钮连续压缩。
  - 只变矮不会把侧栏收成图标；带文字的矮窗仍能看到全部 11 个操作。
- 启动门槛更明确：
  - Windows 低于 `10.0.17763` 时，在创建传输层和主窗口之前提示系统不受支持并退出。
  - WebView2 Evergreen Runtime 必须至少 `123.0.2420.47`。缺失仍走原有下载提示；过旧则单独说明当前版本和最低要求，可下载、重试或退出。
  - 过旧 Runtime 不再进入 WebView 初始化，避免出现 COM 接口转换失败。
- 其他界面修正：
  - 空闲已保存不再常驻顶栏徽章；未保存显示黄徽章，保存成功后绿徽章短暂显示后消失。
  - `野狐(后台落子)` 展示文案改为 `野狐(后台)`，平台值不变。

## 兼容性

- 仍是 WebView2 主线，发布资产为 `readboard-webview2-v3.1.1.zip`。
- 最低系统要求不变：Windows 10 version 1809（10.0.17763）或 Windows 11。
- 更早的 Windows 继续使用 `legacy-windows` 通道上的 v3.0.x。
- LizzieYzy-Next 启动参数和现有逐行文本协议保持兼容。
- 只有声明 `readboardUpdatePackageV2Supported` 的宿主才能托管安装本版本。
- 本 Release 不会改 `update-channels.json`。客户端仍会看到已晋升的 v3.1.0，直到随后单独做通道晋升。

## 验证

- tag 发布时由 `package-release.yml` 跑完整 VerificationTests、benchmark acceptance，并生成 `readboard-webview2-v3.1.1.zip`。
- PR 合入门禁包含 Verification Tests 与 WebView2 Host E2E Core。
