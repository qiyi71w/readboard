# v3.1.0

## 概述

v3.1.0 是 ReadBoard WebView2 主线的首个正式版本。主窗口、参数设置、规则说明、关于、更新和身份选择界面统一迁移到新的 WebView2 视觉系统，同时保留现有棋盘捕获、识别、同步、自动落子、配置和 LizzieYzy-Next 通信行为。

本版本同时接入按 Windows 版本自动选择更新通道的机制。Windows 10 version 1809 及以上系统使用 WebView2 主线；更早的 Windows 系统继续停留在独立的 WinForms 维护线。

## 主要变更

- 使用 WebView2 重写 ReadBoard 用户界面：
  - 新增统一的控制中心、参数设置、规则说明和关于页面。
  - 更新检查、野狐身份选择和辅助确认使用同一套弹层视觉。
  - 支持浅色、深色和跟随系统主题。
  - 保留本地静态资源，不依赖外部网页或前端构建服务。
- 完善响应式窗口和高 DPI 行为：
  - 支持 100%、125% 和 150% DPI。
  - 正常客户区在 `1100 x 680` 到 `960 x 600` 之间等比例缩放。
  - 支持最大化、窗口边缘缩放、多屏恢复和跨 DPI 显示器移动。
  - 在正常支持范围内避免主界面、侧栏和页面级滚动条。
- 接入兼容更新通道：
  - Windows 10 version 1809（build 17763）及以上选择 `main`。
  - 更早的 Windows 系统选择 `legacy-windows`。
  - 通道范围使用下限包含、上限排除语义，并拒绝重叠或非法清单。
  - 无匹配通道、当前版本高于通道、retired 通道和检查失败均有独立状态。
  - 不再根据 GitHub Latest Release 猜测兼容版本，也不会自动降级。
- v3.1.0 使用新的发布资产名称：
  - `readboard-webview2-v3.1.0.zip`
  - 只有声明 `readboardUpdatePackageV2Supported` 的宿主才能执行托管替换安装。
  - 旧宿主面对 WebView2 资产时保留手动下载路径，不尝试不兼容的自动替换。
- 使用系统共享的 WebView2 Evergreen Runtime：
  - 发布包包含 WebView2 SDK 程序集、本地 UI 资源和 `WebView2Loader.dll`。
  - 不捆绑完整 Fixed Version Runtime。
  - Runtime 缺失时使用原生提示提供官方下载入口、重试和退出。
  - 不静默安装 Runtime，也不回退旧 WinForms 主界面。
- 完善同步与界面状态：
  - 原子化停止同步和清空棋盘，防止旧同步任务在清盘后补发状态。
  - 保留专用 `clearBoard` 宿主协议和既有 wire 文本兼容性。
  - 修正快速同步停止后的平台锁定、按钮禁用状态和宿主连接状态。
  - 保留弈客几何落子稳定性、自动落子、GMA 和末手来源行为。

## 兼容性

- 最低主线系统要求为 Windows 10 version 1809（10.0.17763）或 Windows 11。
- 更早的 Windows 系统继续使用 `legacy-windows` 通道和最后已晋升的 v3.0.x WinForms 版本。
- WebView2 主线不会整体合并回 `legacy/winforms`。
- LizzieYzy-Next 启动参数和现有逐行文本协议保持兼容。
- 旧宿主仍可使用 ReadBoard，但不能托管安装新的 WebView2 命名资产。
- 更新检查仍由用户手动触发，不新增启动时自动检查或用户可选通道。

## 验证

- Windows .NET SDK 10.0.104 可构建本版本。
- 更新通道与 Windows 版本识别测试覆盖 1809 边界、旧系统、无匹配、范围重叠、非法清单和稳定 Release 校验。
- 自动落子在持续同步未开启时不得发出 `play>`，由 transport 合同和 5x5 识别 replay 锁定。
- 真实 WebView2 host E2E 覆盖首个权威快照、Control Center bridge、Settings Save/Cancel、analysis 观察和 shell close。GitHub Actions 上已有一次完整通过样本；尚未达到将 core job 升为 required check 的 7 天 / 30 次门槛。
- tag 发布时由 `package-release.yml` 跑完整 VerificationTests、benchmark acceptance，并生成 `readboard-webview2-v3.1.0.zip`。
- 高 DPI / 多屏桌面验收、真实野狐自动落子和 LizzieYzy-Next v2 托管替换重启，不作为本 tag 的已完成声明。托管替换是随后将 v3.1.0 晋升到 `main` 通道的前提。
