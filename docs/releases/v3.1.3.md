# v3.1.3

## 概述

v3.1.3 是 WebView2 主线的同步修复版本。双向落子会等待截图确认；恢复同步或切换平台后，稳定的棋盘也能向宿主提供新的确认帧。

## 主要变更

- 双向同步落子后，每次点击保留 500 毫秒截图确认窗口。窗口内不会重复点击；窗口结束仍未观察到落子时，才按配置的物理点击次数上限重试。确认请求从入队起最多持续 2 秒。
- 持续同步和快速同步发送首次有效盘面后，允许后续独立有效采样再发送一次相同盘面的完整确认帧，帮助宿主在恢复同步或切换平台后完成对齐。之后相同结果继续去重；盘面结果变化后重新取得确认资格。

## 兼容性

- 适用于 Windows 10 version 1809 及以上的 WebView2 主线，发布资产为 `readboard-webview2-v3.1.3.zip`。
- 宿主启动参数和逐行协议文本不变。
- 正式 Release 发布后，`main` 更新通道仍需通过单独的晋升 PR 更新。
