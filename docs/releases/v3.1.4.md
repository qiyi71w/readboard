# v3.1.4

## 概述

v3.1.4 是 WebView2 主线的同步与自动落子修复版本。自动落子每次启用都要重新选择棋色，停止后重新开始同步会恢复自动落子；野狐换房后会重新读取执色；「其他」模式下保存的自定义识别阈值现在生效；宿主断开时 ReadBoard 会先停止收发再退出。

## 主要变更

- 自动落子棋色按启用周期确认：
  - 每次开启自动落子，黑白两个手动选项都未选中，选好棋色后才会向宿主授权落子。
  - 关闭双向同步也会结束本次选择，下次开启需要重新选择。
  - 选择身份时点了取消，本次已经选好的棋色仍然保留。
- 停止同步后重新开始，已开启的自动落子会重新向宿主授权，不用再勾一次。手动关掉的自动落子在重新开始后仍是关闭状态。
- 停止同步时，还在排队或等待截图确认的落子请求会以未响应结束，宿主不会在收到停止通知前删掉本地棋子。连续发现窗口时，标题读取和截图使用同一个窗口。
- 野狐换房后自动执色会刷新：
  - 棋色最多每秒重新读取一次；切换窗口、房间或身份时会马上重新读取。
  - 只读取棋盘所在房间面板里的玩家名单，并且至少要有两名玩家。
  - 支持 `24|6号` 这类复合房号。
  - 棋色读不出来时，自动落子授权会马上撤回；重新读出棋色后会自动恢复，不用换房或重新选身份。
  - 开启诊断后会记录采样和房间上下文。日志里没有昵称，房间号按隐私字段处理。
- 「其他（后台）」和「其他（前台）」模式现在使用已保存的五项自定义识别阈值：
  - 保存后从下一次采样开始使用新值；正在进行的采样仍用旧值。
  - 填 `0` 表示使用默认值。同步间隔单独放在一组。
  - 野狐等原生平台继续使用内置阈值，设置页会显示实际值，但不能编辑。
  - 切换平台时，自定义参数、未保存的修改和错误提示都会保留。
- 宿主连接意外断开（TCP 或标准输入结束）时，ReadBoard 会先停止收发、取消正在进行的识别，然后退出。
- 切换平台时，如果目标窗口已经关闭，会先重新确认目标窗口是否有效，再保存和显示结果。

## 兼容性

- 仍是 WebView2 主线，发布资产为 `readboard-webview2-v3.1.4.zip`。
- 最低系统要求不变：Windows 10 version 1809（10.0.17763）或 Windows 11。更早的 Windows 继续使用 `legacy-windows` 通道上的 v3.0.x。
- LizzieYzy-Next 启动参数和逐行协议文本不变。
- 配置文件格式不变，现有的阈值配置可以直接读取。
- 只有声明 `readboardUpdatePackageV2Supported` 的宿主才能托管安装本版本。
- 本 Release 不会修改 `update-channels.json`。在后续单独做通道晋升之前，客户端看到的仍是 v3.1.3。

## 验证

- tag 发布时，`package-release.yml` 会跑完整 VerificationTests 和 benchmark acceptance，并生成 `readboard-webview2-v3.1.4.zip`。
- PR 合入门禁包括 Verification Tests 和 WebView2 Host E2E Core。
