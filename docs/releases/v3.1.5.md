# v3.1.5

## 概述

v3.1.5 是 WebView2 主线的设置界面修复版本，修复调整窗口大小后无法滚动的问题，并优化识别参数的分组、文字布局和调参提示。

## 主要变更

- 修复设置页在调整窗口大小后滚动条消失、鼠标滚轮无效的问题。内容超出窗口时可以继续滚动，访问底部的保存和取消按钮。
- 设置、规则说明和关于页按实际内容决定是否显示滚动条。
- 识别参数按灰度、黑棋和白棋分组；同种颜色的偏差与识别百分比放在一起，窄窗口下自动调整布局。
- 调整说明文字、默认值、输入区域和提示之间的字号、行距与留白。
- 在识别参数下方增加两条调参提示：
  - 某种颜色的棋子识别过多时，可尝试降低对应颜色偏差或增大占比。
  - 某种颜色的棋子识别丢失时，可尝试增大对应颜色偏差或降低占比。
- 同步中文、英文、日文和韩文提示。

## 兼容性

- 发布资产为 `readboard-webview2-v3.1.5.zip`。
- 最低系统要求不变：Windows 10 version 1809（10.0.17763）或 Windows 11，需要 WebView2 Evergreen Runtime。
- LizzieYzy-Next 启动参数、逐行协议和配置文件格式不变。
- 托管安装需要支持 `readboardUpdatePackageV2Supported` 的宿主。
- 客户端自动更新将在正式发布后的独立通道晋升完成后提供。
