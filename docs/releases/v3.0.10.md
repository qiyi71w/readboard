# v3.0.10

## 概述

v3.0.10 是 WinForms 维护线的稳定修复版本，修复引擎决策落子和自动落子重新授权问题。

## 修复内容

- 修复 GMA 发送 `play>` 后缺少下一次权威棋盘帧，导致宿主持续等待、无法开始自动落子的问题。
- 修复保持双向同步时，关闭后重新开启自动落子不会重新发送授权的问题。
- 拒绝停止自动落子前仍在处理的旧识别结果，避免停止后重新触发过期授权。

## 兼容性

- 继续使用现有 WinForms UI 和 `v3.0.x` 维护线。
- 不改变现有 wire protocol 文本和启动参数。
- 发布资产保持 `readboard-github-release-<tag>.zip` 格式。
