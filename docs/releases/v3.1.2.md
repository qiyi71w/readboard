# v3.1.2

## 概述

v3.1.2 是 WebView2 主线在 v3.1.1 之后的补丁版本。野狐自动落子改为按房间玩家列表的精确昵称确认身份、按名单顺序认色；快速同步过程中的短暂抖动不再丢掉自动落子。同时接入由 LizzieYzy-Next 控制的诊断与采集。

## 主要变更

- 野狐身份按玩家列表昵称确认，棋色跟名单顺序：
  - 身份框列出当前房间玩家列表里的精确昵称。
  - 已保存身份改为昵称文本。此前保存的行字形需要重新选择一次。
  - 名单第一行执白、第二行执黑。第三人、观战、名单为空或对不上名字时保持待识别，不会自动落子。
  - 只影响野狐和野狐(后台)。本次使用、保存并使用、清除保存、取消的操作不变。
- 野狐身份弹层改为紧凑昵称列表：
  - 宽度约 480px，高度随内容。
  - 只显示昵称，不再带候选项截图。
- 快速同步时的短暂中断不再丢掉野狐自动落子：
  - 某一拍同步或颜色暂时认不出时，这一手先不落，授权保留。
  - 关闭自动落子或双向同步时，仍会停止自动落子。
- 接入宿主控制的诊断与采集：
  - 新宿主可以分别开关诊断、完整跟踪和采集，日志写到独立目录。
  - 旧宿主仍用原来的启动参数，行为不变。
  - 指定的日志目录写不了时会明确报告不可用。

## 兼容性

- 仍是 WebView2 主线，发布资产为 `readboard-webview2-v3.1.2.zip`。
- 最低系统要求不变：Windows 10 version 1809（10.0.17763）或 Windows 11。
- 更早的 Windows 继续使用 `legacy-windows` 通道上的 v3.0.x。
- LizzieYzy-Next 启动参数和现有逐行文本协议保持兼容。
- 只有声明 `readboardUpdatePackageV2Supported` 的宿主才能托管安装本版本。
- 本 Release 不会改 `update-channels.json`。客户端仍会看到已晋升的 v3.1.1，直到随后单独做通道晋升。

## 验证

- tag 发布时由 `package-release.yml` 跑完整 VerificationTests、benchmark acceptance，并生成 `readboard-webview2-v3.1.2.zip`。
- PR 合入门禁包含 Verification Tests 与 WebView2 Host E2E Core。
