# v3.2.0

## 概述

v3.2.0 是 WebView2 主线的功能版本。新增置顶的迷你模式；「其他(后台)」可以直接截取 Chrome、Edge、Firefox 等浏览器中的网页棋盘，目标窗口移动后无需重新框选。同时修正部分控件的禁用样式，以及点击分段选项时标题栏移出窗口的问题。

## 主要变更

### 迷你模式

- 完整模式右上角新增「迷你模式」按钮。迷你窗口置顶、大小固定并随显示缩放调整，包含控制中心的全部同步与落子操作。
- 在迷你窗口中可以回到完整模式，也可以直接打开参数设置或规则说明。
- 回到完整模式时，窗口恢复之前的位置、大小和最大化状态，在缩放比例不同的多块显示器之间切换时同样适用。
- 在迷你模式下关闭 ReadBoard，下次启动仍为迷你模式，窗口位置保持不变。
- 身份选择和提示弹窗显示在迷你面板内，窗口大小不变；更新提示只在完整模式中显示。
- 选盘按钮只显示当前平台可用的方式；标题栏会提示偏好设置是否已保存。
- 中文、英文、日文和韩文界面同步提供。

### 浏览器后台取图与窗口移动

- 「其他(后台)」截取 Chromium 内核浏览器（如 Chrome、Edge、Brave）、Firefox 以及采用相同窗口类型的嵌入式程序时，改为捕获完整窗口内容，修复部分网页棋盘截到黑图的问题。首次识别、单次同步和持续同步都不需要开启「强化截图」。
- 框选棋盘后，在同一显示器内移动目标窗口，只要窗口内容区大小、显示缩放和棋盘在窗口中的位置不变，就不需要重新框选。浏览器和其他软件都适用。
- 窗口大小或显示缩放改变、窗口关闭、选区超出窗口时，ReadBoard 会停止使用原来的框选，重新框选即可继续同步。
- 使用条件：目标窗口不能最小化，棋盘需要在屏幕内正常显示且不被遮挡，窗口不需要处于焦点。窗口被完全遮挡、最小化或棋盘位于非活动标签页时，画面不保证持续刷新。网页滚动、页面缩放或内容重排后需要重新框选。

### 界面修正

- 在野狐以外的平台，只有不可用的自动执色和身份入口显示为灰色，手动执黑、执白保持可用外观；完整模式和迷你模式显示一致。
- 「其他(后台)」和「其他(前台)」下不可用的「选择棋盘(点击棋盘内部)」按钮显示为灰色。
- 修复点击颜色模式等分段选项时整页滚动、标题栏移出窗口的问题。

## 兼容性

- 发布资产为 `readboard-webview2-v3.2.0.zip`。
- 最低系统要求不变：Windows 10 version 1809（10.0.17763）或 Windows 11，需要 WebView2 Evergreen Runtime。
- LizzieYzy-Next 启动参数和逐行协议不变。
- 配置文件新增迷你模式状态和迷你窗口位置；已有配置升级后仍以完整模式启动。
- 只有支持 `readboardUpdatePackageV2Supported` 的宿主才能托管安装本版本。
- 正式发布后还要单独完成通道晋升，客户端才能自动更新到本版本。
